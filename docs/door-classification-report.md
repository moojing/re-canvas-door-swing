### 對原 130 小時總估的影響方向

- **可往上加(救回)**:目前仍有 13 個「比評估樂觀」項目,另有 4 個需重估項目未定。可救回內容仍不少,但是否納入要看 POC 品質門檻與專案範圍,不能再把「能做概形」直接當成可交付。
- **應往下扣(剔除)**:2 個原本列了工時、被當成可做的項目,實際依獨立性規則無法製作,**應從總估剔除約 7 小時**(1-2 c04 滑梯 4h、1-4 c08 繩索 3h)。

## 2. 有出入 / 需再確認清單

### 2A. 原評估「可做」,實際無法製作或難度非常高 ★最需注意

這是你特別要求標記的類別——原本以為做得到、實際上做不到或嚴重低估的項目。

| 門型 | 原評估 | 實際判定 | 說明 |
|------|--------|----------|------|
| **1-2 c04 滑梯** | 8 / **4h**(可做,附模型連結) | **❌ 應歸零** | 轉場本體是「鏡頭在風管通道內高速滑行」,環境即動畫,拆掉通道沒有可獨立的門件。唯 s3 開頭約 1 秒的鐵柵窗掀蓋可獨立。 |
| **1-4 c08 繩索** | 1 / **3h**(可做) | **❌ 應歸零** | 整段是第一人稱沿繩垂降到窄巷,無任何門板,鏡頭運動完全依賴環境。獨立性規則明文舉例的類型。 |

  - 1-2 b07 大電梯門雖已寫回 3h,但鋸齒輪廓、門面咬合與原片還原度是否達標仍未定,現改列 `⚠️需重估`;其重複鏈下游 `1-3 b06` 也因此不宜直接沿用。

- **CSV 變體編號錯誤**:1-3 a03 備註說「a02-s3 有柵欄」,實際柵欄款是 a02-**s16**(s3 是素面平鐵門)。

## 3. 無法製作清單(依「動畫須能獨立存在」規則 / POC 驗證)

規則:轉場動畫必須能以「門體(或轉場物件)+ 全黑背景」獨立成立;若依賴環境(載具內裝、搭乘段、環境即動畫)且拆掉環境後不成立,判定無法製作。「載具門要連環境一起做」這種情況不存在——除非動畫能獨立,否則標為無法製作。另有少數門型雖可獨立抽離,但經 POC 驗證後仍無法在可接受成本內完整重現,也歸入本區。

### 最小實作組合建議

從上表可以看出,113 個門型的動畫多樣性其實極低——絕大多數落在少數幾套骨架上。若要用最少工程覆蓋最多門型,優先順序:

1. **鉸鏈單開 + 鉸鏈雙開(+ 鏡頭穿越)** — 涵蓋所有 a/b 類一般門,是絕對主力(約佔可做門型的 6 成以上)。你們現有的 `DoorAnimation3D`(開門 → 鏡頭前進 → 淡出)就是這一套,單門版已完成。雙門版只是加一片鏡像門板。
2. **水平滑動 + 中分滑動** — 涵蓋所有拉門、自動門、電梯門(僅門體)。中分滑動 = 兩片對開的水平滑動,骨架共用。
3. **純鏡頭移動** — 涵蓋可製作的 c 類階梯/直梯/鑽洞,不需門模型,只需場景幾何 + 鏡頭路徑。
4. **少數特例骨架**:雙門僅單扇開(參數化:開一扇 / 兩扇)、垂直上升/捲升、窄雙板折疊。各只服務 1–3 個門型,可視優先級決定是否做。

**配件**才是真正需要逐一準備的資產,但也可歸納成一組可重用元件:無把 / 喇叭鎖 / 豎把 / 橫把 / 彎把 / 斜把 / 圓環 / 門栓 / 轉盤鎖 / 自動(無配件)。這 10 種把手 + 上述約 4 套動畫骨架 + 逐門換的平面貼圖,即可組出全部可做門型。

**結論**:成本幾乎不在「動畫」(骨架就這幾套),而在**配件模型**與**逐門貼圖量**。原 CSV 的 130 小時裡,真正的變異來自後兩者,而非動畫本身。
