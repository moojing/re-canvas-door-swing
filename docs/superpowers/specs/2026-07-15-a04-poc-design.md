# 1-2 a04 PoC Design

## Goal

Build a throwaway proof-of-concept page for `1-2 a04` that can switch between the two observed variants:

- `s1`: 柵欄鐵門
- `s2`: 目字鐵門

The PoC is for feasibility validation, not pixel-perfect restoration.

## Scope

- Add a dedicated `/poc/a04` page in the sample app.
- Reuse one shared single-door hinge animation and camera timeline.
- Switch only the door leaf geometry between `s1` and `s2`.
- Provide simple controls for variant switch, play, reset, and scrub.

## Acceptance Criteria

- `s1` reads as a low-complexity barred metal door built from repeated primitives.
- `s2` reads as a low-complexity framed metal door with non-zero thickness, not a flat texture card.
- Both variants open convincingly enough to support the `4–6h` feasibility estimate.

## Non-Goals

- No library preset integration yet.
- No texture extraction pipeline.
- No final art polish or shot-matching.
