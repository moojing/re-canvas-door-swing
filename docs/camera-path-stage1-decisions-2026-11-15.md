## 2026-11-15 Stage1 已確認的設計決策

本節記錄作者確認的範圍，補充原設計提案；不代表功能已實作。

- 使用對象：僅供專案作者校準的工作台。正式網站的公開 editor 不在本次範圍。
- 第一版只調目前 preset 的門高、停留與鏡頭前進速度，保留原始路徑，不提供鏡頭模板切換。
- 以原片比例作為校準基準，另提供手機預覽檢查。可在相同時間點比較桌面／平板／手機構圖；不預設所有 viewport 都強制維持同一門高百分比。跨尺寸比例、偏心投影及超過 100% 的精確計算規則仍需實作設計與視覺驗證。
- 明確區分「鏡頭停留」「開門前等待」「鏡頭前進速度」。鏡頭-only 編輯保留其他 tracks 的時間；共同的開門前等待變更須協同 retime 相關門板、把手、聲音與淡出。各 set 支援哪些控制及 phase anchor 映射仍待細化，不新增獨立 scheduler。
- 第一版採頁面內暫存與還原原設定；Reset 只重設播放，不丟棄調整，Restore 還原原始設定。不在此階段加入跨重整保存或匯出。
- Enter／Leave 共用尚未確認；不把本次同意解讀為批准共用、方向覆寫或自動建立缺少的方向。保留既有 distinct paths。

後續仍待設計：控制範圍／phase 映射、精確投影與 resize 規則、Enter／Leave 共用、版本化保存／匯出與自訂 preset 註冊。正式校準結果如何帶回程式碼也需後續決定。

狀態維持 Open／In Progress；Stage2 已完成，Stage1／Stage3 尚未實作。無新來源完成、合併或發布，35 支總覽計數不變。

## Stage1 本機實作說明

- 入口沿用 `npm run dev:calibration`，一般 dev 與 production 不顯示作者控制。工作台的單一預覽固定為1280×800校準視窗；裝置比較沿用Desktop／Tablet／Phone與既有直式適配。
- 門高依實際閉門幾何（高6、單門寬3／雙門寬6、表面深度−0.002至0.162）及60度垂直視角求投影，不截斷至100%。維持視線目標，沿視線調整距離；開場與靠近結束的距離修正平滑銜接，尾端回到原始路徑終點。
- 「鏡頭停留」增加起步停留，再將剩餘鏡頭進度分配至原有總時長。「鏡頭前進速度」調整進度分布，1×保留原分布，大於1較早前進；不改總時長或其他 tracks。兩者都可能改變鏡頭與開門的相對時機，必須播放檢查。
- 「開門前等待」增加既有關門等待區間，使用相同warp／phase retiming延長總時長、後續events及門板／把手／鏡頭／聲音／音量淡出／畫面淡出。舊階段編輯器仍編輯增加等待前的時間，避免重複加上等待；主時間軸顯示最終時間。
- 無閉門構圖的狂奔門不提供門高與開門前等待；沒有approach-end的路徑不提供靠近後門高。控制項顯示原因。無效輸入保留最後有效預覽。
- 草稿暫存在目前頁面，依完整preset ID隔離。切換方向不共用、不丟棄另一方向草稿。Reset只重設播放，Restore只清除目前preset的草稿；重整頁面全部清除。
- 此為本機未提交實作，未合併／未發布。完整交付與檢查證據另記於#72及repo進度；Stage3仍待做。不宣稱來源精確重製。

- 直式安全距離快取在有效草稿套用後失效重算，避免只改速度／停留時沿用舊路徑。回歸先重現不同畫面，再驗證相同最終草稿、相同進度在重新計算後逐位元組一致；修正後作者控制與裝置比較7項通過。獨立複查核准。

## 同日後續確認：AI／人類溝通與手機構圖

本節取代前文仍把匯出、保存或模板列為必要後續工作的說明。

- 工作台只作為作者與 AI 溝通畫面的橋樑，草稿可直接清除。不要因正式校準而強制加入匯出、持久保存、檔案版本或相容性流程；後續由 AI 依回饋修改程式碼。
- 不加入鏡頭模板，不把統一運鏡套用到每個動畫。Enter／Leave 繼續是獨立 preset，不自動連動草稿。
- 手機可獨立覆寫開場／靠近後門高，以及水平／垂直構圖偏移；留空繼承共用門高或零偏移。停留、速度、等待與所有非鏡頭 tracks 共用。
- 手機定義為預覽邏輯尺寸的短邊不超過600px，含橫向；不是依裝置型號或縮放後的卡片尺寸判定。Desktop／Tablet／Reference 比較窗維持共用設定。
- 門高保留手機適配前的完整關門投影定義，最終可見門高仍受直式安全適配影響，不能把輸入數字當成適配後的精確量測值。正向偏移向右／向上移動畫面，透過投影取景處理，不增加繞門運鏡。
- 詳見[手機構圖設計](superpowers/specs/2026-11-15-phone-camera-framing-design.md)與[實作計畫](superpowers/plans/2026-11-15-phone-camera-framing.md)。本機工作未合併／未發布。
