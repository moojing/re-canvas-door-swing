# 開門動畫檢查紀錄(全 113 門型)

## 檢查方法與範圍

- **檢查期間**:2026-07-05 ~ 2026-07-07,分 21 個批次完成,涵蓋 1-1 ~ 1-5 五部作品共 113 個門型(含全部變體影片抽驗)。
- **方法**:每個門型取代表影片抽分鏡截圖(自動跳過黑幕段),對機構可疑的變體另行補抽影格核對;依五軸(**形式 / 動畫 / 配件 / 材質 / 聲音(推斷)**)分類判讀,再對回 `docs/Doors-Difficulity-Estimation.xlsm.csv` 的評估列(難度、時數、風險標記、備註)逐項核對。
- **獨立性規則**:轉場動畫必須能以「門體(或轉場物件)+ 全黑背景」獨立成立才算可製作;依賴環境(載具內裝、搭乘段、環境即動畫)且拆掉環境後不成立者,判定無法製作。
- **核對結果標記(五種)**:
  - **✅合理** — 影片判讀與 CSV 評估相符(含 CSV 判 ❌ 且理由成立者)。
  - **✅比評估樂觀** — CSV 判不可做或成本過高,實看後可用貼圖 / 基本幾何 / 程序化建模解決,建議翻案。
  - **⚠️有出入** — 判讀與 CSV 有具體落差(引用錯位、配件不同、工時漏列、範圍低估等),需修正評估內容。
  - **⚠️需重估** — 該列的評估前提有誤,需拆項或重新定義範圍後再估。
  - **❌無法製作** — 依獨立性規則不成立(環境即動畫 / 搭乘段 / 角色演出為主體)。
- **CSV難度/時數欄**:格式為「難度/時數」;重複項標「重複(引用對象)/時數」;附原表風險標記(⚠️❌❓＄)。
