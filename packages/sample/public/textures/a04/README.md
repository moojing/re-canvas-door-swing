# A04 PoC Material Sources

These maps are low-resolution source ingredients for the `1-2 a04` proof of concept. They are not copied from the reference game footage.

- `metal-plate-02-*`: [Poly Haven Metal Plate 02](https://polyhaven.com/a/metal_plate_02), used on the warm, barred `s1` gate.
- `green-metal-rust-*`: [Poly Haven Green Metal Rust](https://polyhaven.com/a/green_metal_rust), desaturated for the cold, damp `s2` door.
- `sewer-gate-aged-albedo.png`: retained legacy generated albedo, not loaded by the current PBR material registry.
- License: [CC0](https://polyhaven.com/license). The source maps may be used and modified, including commercially.

The PoC uses tinting, different map repetition, roughness, and lighting to create a distinct damp underground-parking interpretation. It must not reproduce the original game's pixel art, exact rust pattern, or scene imagery.
