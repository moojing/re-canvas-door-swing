# C06 texture provenance

Both textures are original project assets generated with the built-in OpenAI image generation tool on 2026-07-17. The generated images were resized to 1024 x 1024 and tagged with the sRGB IEC61966-2.1 profile for browser and Three.js use.

- `aged-brick-albedo.png` is the repeating front-face material for intact wall panels and the front/back faces of edge bricks.
- `broken-brick-core-albedo.png` is a non-directional brick-core and mortar material for the exposed tunnel and cut faces. It avoids stretching a front-facing brick bond over right-angle cross sections.

No source-video frame, game texture, character, prop, logo, or other protected asset is included in the generated image. The source video was used only to identify the broad material category: a dark, damp brick wall.

## Wall prompt

> Use case: stylized-concept. Asset type: production-ready seamless diffuse/albedo tile for a real-time 3D brick wall. Create a genuinely seamless, endlessly repeatable square tile of an original old damp brick wall. The pixels, brick courses, mortar lines, color, and texture must wrap continuously across left/right and top/bottom edges with no visible seam in a 3x3 repeat. Front faces of irregular old rectangular fired-clay bricks in staggered running bond with recessed lime mortar; no opening. Realistic hand-authored game albedo map, orthographic straight-on, texture-only surface scan. Strictly flat diffuse color; neutral overcast capture; remove directional highlights, cast shadows, ambient-occlusion halos, vignette, and gradients. Dampness appears as color variation only. Deep umber, muted oxblood, soot brown, dirty warm-grey mortar, sparse desaturated moss. Restrained chips, water staining, mineral bloom, and mortar variation; balanced low-frequency detail without a unique focal stain. Exact 1:1 square tile; seamless on all four boundaries; entirely original; no hole, arch, fireplace, characters, props, text, symbols, logo, watermark, border, perspective, dramatic lighting, specular shine, or copied composition.

## Broken-core prompt

> Use case: stylized-concept. Asset type: production-ready seamless diffuse/albedo tile for exposed broken-brick cross sections in a real-time 3D wall. Create a genuinely seamless, endlessly repeatable square material showing the rough cut interior of old fired-clay bricks mixed with crumbly lime mortar. This is for the inner tunnel faces of a jagged hole, not for the wall front. All four image boundaries must wrap continuously with no seam in a 3x3 repeat. Irregular granular brick cores, broken terracotta aggregate, dusty mortar pockets, small chips and hairline cracks; no recognizable front-facing brick courses. Realistic hand-authored game albedo map, orthographic texture-only surface scan. Strictly flat diffuse color; neutral overcast capture; no directional highlights, cast shadows, ambient-occlusion halos, vignette, or gradients. Dark burnt sienna, muted clay red, soot brown, dusty warm-grey mortar, sparse desaturated moss specks. Evenly distributed medium-scale granular variation with no central focal feature and no long straight mortar rows. Exact 1:1 square; seamless on all four boundaries; entirely original; no wall opening, brick facade, characters, props, text, symbols, logo, watermark, frame, perspective, dramatic lighting, specular shine, or copied composition.
